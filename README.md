# Python Banking System

A console-based Banking Management System developed using Python and Object-Oriented Programming.

## Features

- Create Savings and Current accounts
- View account details
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Calculate interest
- View all accounts
- Input validation and error handling

## OOP Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Method Overriding

## Technologies

- Python
- Object-Oriented Programming
- Python Datetime Module

1. Clone the repository.
2. Open the project folder.
3. Run:
